# ADR 003: Possession-level game engine

**Status:** Accepted for the first playable model

## Context

A single strength roll cannot explain games or guide the player-attribute schema. Play-by-play is premature complexity.

## Decision

Resolve games through roughly 20–28 possessions using unit strength, quarterback quality, scheme, field position, fatigue, coaching, home advantage, turnovers, and explosive-play variance.

## Consequences

The model can create credible scores, comebacks, and upsets with manageable runtime and schema size. Greater detail requires evidence that it enables meaningful decisions.
