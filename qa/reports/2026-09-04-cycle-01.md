## Verdict

The game is **playable and stable, and not ready for testers.** A cold player
completed a full season, made the playoff, survived a board review and carried on
into season two without hitting a crash — the loop holds. But the same player
finished the season unable to name a single decision that caused a win, and the
first instruction the game gave them appeared to break it.

Two invariants are broken. One of them, the save/load divergence, undermines the
reproducibility this whole process depends on.

**Recommendation: fix first.** Three P2s and one P1, all small, all found inside
one cycle. None is a redesign.

### P1

**01 — save/load divergence.** The save deliberately trims `eventHistory` from
10,024 rows to 400; that is correct and documented. The defect is that
`selectFacilityUpgrade` *reads* that log to derive `lastWeeklyNet`. After a load
every program reads 0, and **six of twenty-four make a different facility
decision** as a direct result. Divergence compounds every season.

Introduced by `0a8ba8a`. Before that change nothing in the engine read the event
log to make a decision, so trimming it was safe. The rule it breaks is worth
stating generally: **the event log is a record, not gameplay state.**

The existing repo test asserts exactly this invariant and passes — its scenario
does not span a week-1 facility decision with populated finance history. The
assertion is right; the scenario is too narrow.

### A process note worth keeping

Every one of the four fixes needed a measurement before it was safe to make, and
two of them contradicted something written down:

- Issue 02's suggested fix location was wrong. The command it called out as
  out-of-phase is accepted by the engine, and `game-rules.md` — which the agents
  read as ground truth — was the thing that was incorrect.
- Issue 04's cause was filed as unknown. It was systematic, at 10% of flagged
  posts, and would not have been visible from one more repro.
- The P1's existing test passed because it handed both sides of the comparison
  the same trimmed event log. **A test that has not been run against the defect
  is not a regression test** — every new assertion here was confirmed red first,
  and two drafts were thrown away for passing vacuously.
