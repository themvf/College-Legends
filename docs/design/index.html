Design Studies

Standalone HTML mockups for College Legends, none of them wired to the app. Each explores a visual direction for a real screen using real content from packages/content, so the treatments can be compared against each other rather than against a description. They run in order — each one answers something the previous one raised.

01IdentityReference

Shield System

program-marks.html

Five program marks drawn from real generated programs, each shown at four sizes on both grounds.

Keystone Commonwealth, Lake Erie, Lone Star Metropolitan, Crescent City and Front Range — picked so each program character has a mark. Establishes the rule that a dark shield needs a keyline to survive on a dark UI.

02Moneyball × ArcadeReference

Scoreboard Math

scoreboard-math.html

A single amber-CRT hue carrying both the numbers and the drama.

Treats a game result as a high score and the roster as a data table, on the argument that the sim's appeal is arithmetic that happens to be exciting. Names its own three risks at the bottom.

03Three-wayReference

Three Screens

three-treatments.html

Bloomberg × Moneyball, Bloomberg × Arcade, and Palantir × Arcade on identical content.

One recruiting board rendered three ways, deliberately with the same four prospects and the same numbers, so anything that differs between them is a design decision rather than a content difference. Closes recommending the Palantir treatment.

04BroadcastCurrent

War Room

war-room-mockup.html

Broadcast-scorebug UI: circular gauges, italic condensed numerals, a yard-line divider.

Started from a racing UI kit, then retextured for football and repalletted to field green and leather brown. The argument it lands on is that the percentage circle and the italic numeral were already football's own language — recruiting sites and scorebugs got there first.

Open any file directly in a browser; there is no build step and no external dependency. Studies 01–03 follow the viewer's light or dark theme. Study 04 deliberately commits to a single dark ground — it is a night-game broadcast look, and inverting it would defeat the point.
