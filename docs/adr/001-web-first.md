# ADR 001: Web-first delivery

**Status:** Accepted

## Context

The game will require frequent balance iteration. App Store review would slow early learning, while the management interface maps naturally to browser technology.

## Decision

Build a private, desktop-primary responsive web alpha before iOS. Keep the domain and simulation platform-neutral. Phone support must not dilute dense desktop workflows.

## Consequences

Iteration and tester access become faster. A Web Worker and browser-safe state shape are required. iOS packaging remains a later evaluation rather than an early dependency.
