# Visual design exploration

Standalone HTML mockups, not wired to the app. Each is a self-contained page
exploring a visual direction for a real screen using real content from
`packages/content`, so treatments can be compared fairly against each other.

## war-room-mockup.html

Fourth of four recruiting-board direction studies (the other three —
Bloomberg x Moneyball, Bloomberg x Arcade, Palantir x Arcade — were built and
discussed but not committed). Broadcast-scorebug UI: circular percentage
gauges for sign probability, italic condensed numerals, a yard-line divider,
field-green and leather-brown as the accent pair. Started from the "Asphalt
Legends" racing UI kit as a reference point, then retextured for football and
revised for contrast once the racing palette proved hard to read.

Open the file directly in a browser to view it.
