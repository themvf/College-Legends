# Issues

One file per confirmed defect. A finding only becomes an issue after the QA lead
has reproduced it and assigned a severity — the reporter does not set severity.

`YYYY-MM-DD-NN-<slug>.md`, e.g. `2026-09-04-01-save-round-trip-drift.md`.

Copy `_template.md` to start. Severity definitions are in `../qa-process.md`.
